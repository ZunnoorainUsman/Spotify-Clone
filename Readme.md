# 🎵 Spotify Clone

A responsive Spotify-inspired music player built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Responsive design for desktop and mobile devices
* Play and pause music
* Song list display
* Custom music player UI
* Dynamic song loading
* Clean and modern Spotify-inspired interface
* Interactive controls built with vanilla JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📸 Preview

This project recreates the look and feel of Spotify while focusing on frontend development concepts such as DOM manipulation, event handling, asynchronous JavaScript, and responsive design.

## 🔧 Installation

1. Clone the repository

```bash
git clone <your-repository-url>
```

2. Open the project folder

3. Run a local server (recommended)

4. Open the project in your browser

## ⚠️ Audio Files Not Included

The audio files used during development are not included in this repository due to file size and copyright considerations.

To run the project locally:

1. Create a `songs` folder in the project root.
2. Add your own `.mp3` audio files to the folder.
3. Update `info.json` if necessary to match your song files.

The application logic and music player functionality remain fully implemented and can be tested using any audio files of your choice.
